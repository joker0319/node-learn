# node-learn：Node.js 后端学习仓库

从零开始学 Node 后端。每课一个文件夹：**代码（带逐行注释）+ NOTES.md（原理讲解 + 作业）**。

环境：Node v22.22.2

## 学习路线

| 课 | 主题 | 状态 |
|----|------|------|
| 01 | 纯 http 模块手写服务器（路由、请求响应） | ✅ 当前课 |
| 02 | 原生 http 处理 POST / JSON（完整 TODO 接口） | ✅ 当前课 |
| 03 | fs 文件系统：数据真正存起来 | 待学 |
| 04 | Express 重写：路由 + 中间件 | 待学 |
| 05 | 数据库：SQLite + 增删改查 | 待学 |
| 06 | 事件循环 / 异步原理（面试重点） | 待学 |
| 07 | 登录鉴权 JWT、错误处理、CORS | 待学 |

## 怎么学

1. 看当前课的代码（每行都有注释）
2. 跑起来：`npm run l1`（数字对应课号）
3. 读 NOTES.md，完成文末的 3 个动手作业
4. 完成一课，把状态列改成 ✅，再开始下一课
